# PookieBlinder_maharashtra_round
## Quick start

```bash
make setup   # venv, dependencies, .env, migrations (no Docker, no API keys needed)
make dev     # API on :8000 and web on :3000 (web starts once frontend/ exists)
make test    # backend test suite
```

See `docs/LOCAL_FIRST.md`, `docs/ARCHITECTURE.md` and `docs/BACKEND_FOUNDATION.md`.
